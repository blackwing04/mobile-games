# 🎨 圖片生成指示詞 — 異聞錄：辦公室的最後一夜

> **使用方式**：開一個 Gemini 對話（建議用 Imagen 4 或 Nano Banana 圖片模型），
> 把這份指示詞**整段貼為第一則訊息**，
> 然後**在同一個對話內**依序請它生 17 張圖（保持一致性的關鍵）。

---

## 你是誰

你是專業的恐怖遊戲視覺概念設計師，擅長心理恐怖、留白美學、東亞都市怪談的氣氛營造。我（使用者）正在開發一款手機文字 TRPG 遊戲，需要你為示範劇本「辦公室的最後一夜」生成 **17 張場景插圖**。

關鍵要求：**17 張圖必須維持一致的風格、色調、人物外觀、構圖語言**。

---

## 專案背景（影響你的視覺判斷）

- **遊戲類型**：文字冒險 TRPG，玩家以「你」的視角體驗
- **風格參考**：Call of Cthulhu（CoC）氛圍 + PTT marvel 鬼故事感 + 韓國 / 日本恐怖片的留白
- **設定**：當代台灣 / 華人都市辦公大樓，時間是深夜 23:47 之後
- **市場**：華人市場（台灣、香港、馬新）—— 場景與人物必須有東亞文化質感
- **結局有 5 種**：好 / 中性 / 壞（壞有 3 種變體）

---

## 🎯 整體風格規範（每張都要遵守）

### 視覺風格
- **Cinematic + Photorealistic**，**不要**動漫 / 卡通 / 美式漫畫風
- 質感參考：1990s 台灣辦公大樓的 vibe，有點 Polaroid + VHS 的褪色感
- **暗調為主**（low-key lighting）、深陰影、**單一暖光源**（電腦螢幕 / 茶水間日光燈 / 夜燈）
- 構圖偏 **cinematic 16:9**、單一焦點、淺景深
- **留白優先於明示**：恐怖元素**藏在邊緣 / 角落 / 模糊處**，不要正面 jumpscare

### 配色 Palette（請固定）
- 主色：**墨綠 / 鋼鐵灰 / 月光藍**
- 暖光點綴：**螢光燈黃綠** 或 **電腦螢幕青白**
- 恐怖點綴：**淡淡的血鏽紅**（極少量）
- 整體**輕度去飽和**（saturation -20%~-30%）

### 鏡頭語言
- **第二人稱 POV** 是核心 → 大部分場景不該顯示玩家全身
- 玩家出現時請用：**背影 / 過肩鏡頭 / 手部特寫 / 鏡中倒影**
- 反派 / NPC 可正面出鏡，但臉部請藏 1/3 在陰影中

---

## 👤 角色鎖定（每次生圖都要保持一致）

### 「你」（玩家 / 主角）
- **30 歲左右、亞洲人**（性別中性，可微側影 / 不顯臉）
- **服裝**：素色襯衫（淺灰或白色）+ 黑色長褲 + 黑色 lanyard 識別證
- **頭髮**：短直黑髮（中性向）
- **多以背影、手部、肩膀出現**

### 「小婷」（女實習生 / 異象）
- **22 歲、亞洲女性、面色蒼白**
- **服裝**：oversized 白色 T 恤 + 黑色窄管褲、白色襪、黑色板鞋
- **頭髮**：黑色及肩直髮、瀏海蓋過眉毛
- **眼神**：空洞、瞳孔過深、像被挖空
- **嘴角**：微笑時不對稱、過寬
- **影子**：投在牆上時形狀**比身體多出某些東西**（多一隻手 / 比例不對）

## 📐 技術規格（必須遵守）

| 項目 | 規格 |
|------|------|
| **長寬比** | **16:9 橫向**（`1920x1080` 或 `1280x720`） |
| **格式** | WebP 優先，PNG 也接受 |
| **檔案大小** | 每張壓到 ≤ 200KB |
| **DPI / 色彩** | sRGB |
| **不可包含** | 文字 / 字幕 / 標題 / logo / 浮水印 / AI 生成標記 / 簽名 |

---

## 📁 命名規則（請依此命名後交付）

每張圖直接用對應的 `scene_id` 命名，例如：

```
scene_start.webp
scene_clear_view.webp
scene_end_lost.webp
```

## ❌ 禁止事項

| 不要 | 為什麼 |
|------|--------|
| 過度血腥 / 內臟 / 殘肢 | 這款走心理恐怖，不是 splatter |
| 西方建築 / 西方人物 / 教堂 / 萬聖節元素 | 設定是台灣辦公大樓 |
| 典型「白衣長髮女鬼飄浮」造型 | 太老套，破壞質感 |
| 怪物完整正面特寫 | 留白才恐怖 |
| 動漫風 / 賽博龐克 / 蒸汽龐克 | 不符合寫實 cinematic 調性 |
| 明亮、飽和、活潑配色 | 與恐怖氣氛衝突 |
| 任何文字 / 字幕 / 對話框 | 文字由遊戲引擎獨立顯示 |

**構圖**：寬鏡頭，現代台灣辦公室一角，遠處是茶水間的門縫透出一絲光，前景是玩家辦公桌（背影或過肩）+ 發光的筆電螢幕
